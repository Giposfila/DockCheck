# DockCheck

> **Помощник студенту для проверки и оформления учебных работ по требованиям конкретного учебного заведения.**

---

## 🎓 Проблема

Оформление отчётов, лабораторных и курсовых работ часто превращается в отдельную задачу: нужно искать методички, запоминать требования к шрифтам, отступам, заголовкам, таблицам, рисункам, нумерации и структуре документа.

При этом требования отличаются между университетами, кафедрами и даже отдельными дисциплинами.

**DockCheck** предлагает перенести эту рутинную проверку из ручного режима в понятный автоматизированный процесс.

---

## 💡 Идея проекта

Пользователь загружает учебный документ и выбирает **стандарт или методические требования** своего учебного заведения.

DockCheck анализирует документ и показывает:

- 🔴 **ошибки** — требования явно нарушены;
- 🟡 **предупреждения** — есть потенциальная проблема, требующая проверки;
- ⚪ **непроверяемые пункты** — правило нельзя надёжно определить автоматически;
- 🟢 **соответствия** — требование выполнено.

Каждая найденная проблема сопровождается объяснением: **что не так, какое правило нарушено и что нужно исправить**.

---

## ⚙️ Как это работает

**1. Загрузить документ** → DOCX / PDF  
**2. Выбрать требования** → стандарт университета, кафедры или собственный профиль  
**3. Проверить** → DockCheck анализирует структуру и оформление  
**4. Исправить** → пользователь получает понятный список замечаний  
**5. Повторить проверку** → документ проверяется снова перед сдачей

---

## 🧩 Что можно проверять

| Категория | Примеры |
|---|---|
| 📄 Структура | титульный лист, содержание, разделы, приложения |
| ✍️ Текст | шрифт, размер, интервалы, абзацы, выравнивание |
| 📐 Страница | поля, ориентация, размеры страницы |
| 🔢 Нумерация | страницы, рисунки, таблицы, формулы |
| 🖼️ Рисунки | подписи, ссылки в тексте, нумерация |
| 📊 Таблицы | оформление, подписи, нумерация |
| 📚 Ссылки | библиография, ссылки на источники |
| 📋 Общие требования | правила конкретного вуза или кафедры |

## 🎯 Для кого

**Студентам** — быстро проверить работу перед сдачей и понять, что именно нужно исправить.

**Преподавателям** — сократить время на первичную проверку формальных требований.

**Кафедрам и вузам** — хранить требования в структурированном виде и использовать единый подход к проверке.

---

## 🚀 Ценность

**DockCheck не пишет работу вместо студента.**

Он помогает убрать рутинную часть подготовки документа и сфокусироваться на содержании.

> **Написал работу → проверил требования → исправил замечания → сдал.**

---

## 🛠️ Концепция развития

Проект рассчитан на расширение: от базовой проверки DOCX до системы профилей требований разных учебных заведений, автоматического формирования отчёта о нарушениях и интеграции с учебными платформами.

**MVP:** загрузка документа → выбор стандарта → автоматическая проверка → отчёт с замечаниями.

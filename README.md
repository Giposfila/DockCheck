# ДокЧек

Приватный браузерный проверщик DOCX по машинно-проверяемым требованиям СТУ СФУ 7.5-07-2021.

Файл разбирается локально в браузере: приложение не загружает его на сервер и не сохраняет содержимое. Проверяются параметры страницы, базовая типографика, заголовки, подписи таблиц и рисунков, структура, ссылки и нижний колонтитул. То, что зависит от визуальной вёрстки или смысла, выводится отдельным списком ручной проверки.

```bash
npm install
npm test
npm run build
npm run dev
```

Требования можно настроить в интерфейсе; шаблон хранится только в `localStorage` браузера.
